# ระบบ LPA / HPA 2568–2569 จังหวัดจันทบุรี

ระบบนี้ทำให้ GitHub Pages อัปเดต Dashboard อัตโนมัติเมื่อมีการเปลี่ยนไฟล์ในโฟลเดอร์ `data`

## ไฟล์ข้อมูล
- LPA 2568.xlsx
- LPA 2569.xlsx
- HPA 2568.xlsx
- HPA 2569.xlsx
- ยืนยันข้อมูล 2568.xlsx
- ยืนยันข้อมูล 2569.xlsx

## วิธีอัปเดตในอนาคต
1. แทนที่ไฟล์ Excel ในโฟลเดอร์ `data`
2. Commit changes
3. GitHub Actions จะประมวลผลและสร้าง `index.html` ใหม่
4. GitHub Pages จะเผยแพร่เวอร์ชันใหม่

แนะนำให้อัปโหลดเป็น `.xlsx` ไม่ใช่ `.xls` เพื่อให้ระบบอัตโนมัติทำงานเสถียร
