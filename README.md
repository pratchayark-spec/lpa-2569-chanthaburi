# LPA 2569 จังหวัดจันทบุรี

เว็บ Dashboard จากข้อมูล LRP001 และ HPA001 ที่ส่งมา

## นำขึ้น GitHub Pages
1. สร้าง Repository ใหม่ใน GitHub เช่น `lpa-2569-chanthaburi`
2. อัปโหลด `index.html`
3. ไปที่ Settings → Pages
4. เลือก Deploy from branch → `main` → `/root`
5. บันทึก แล้วเปิด URL ที่ GitHub สร้างให้

## หมายเหตุ
เว็บนี้เป็น static site ข้อมูลถูกฝังไว้ใน `index.html` จึงเปิดได้ทันทีโดยไม่ต้องมีฐานข้อมูล
หากต้องการอัปเดตข้อมูลภายหลัง สามารถนำ LRP001/HPA001 ชุดใหม่มาให้ระบบสร้างไฟล์ใหม่ได้
