# LPA จังหวัดจันทบุรี 2568–2569

เว็บสรุปผล LPA/HPA สำหรับจังหวัดจันทบุรี โครงสร้างเลียนแบบรูปแบบการใช้งานของเว็บ LPA ส่วนกลาง โดยแยกฐานข้อมูลปี 2568 และ 2569 และมีหน้าการเปรียบเทียบ

## โครงสร้างข้อมูล
- data/2568/lpa.json
- data/2568/hpa.json
- data/2569/lpa.json
- data/2569/hpa.json
- data/compare.json
- data/meta.json

## GitHub Pages
อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดโดยคงโครงสร้างเดิม จากนั้น Settings → Pages → Deploy from a branch → main → / (root)

ไม่มีระบบสถานะยืนยันข้อมูลตามที่กำหนด


## แผนที่จังหวัดจันทบุรี
เพิ่มแผนที่ขอบเขต 10 อำเภอของจังหวัดจันทบุรีแบบคลิกได้ โดยใช้ GeoJSON ขอบเขตอำเภอจากชุดข้อมูลสาธารณะ และเชื่อมสีตามค่าเฉลี่ย LPA ปี 2569


## V7 Map Fix
แก้ไขการคำนวณพิกัด SVG ของแผนที่อำเภอ ซึ่งเป็นสาเหตุให้แผนที่แสดงเป็นจุด/เส้นเล็ก ๆ ทางซ้ายของกรอบ
