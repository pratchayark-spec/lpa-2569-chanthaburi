# LPA 2568–2569 จังหวัดจันทบุรี

เว็บ Dashboard เปรียบเทียบ LPA 5 ด้าน และ HPA ด้านที่ 6 ของ 82 อปท. พร้อมค้นหา/กรอง/จัดอันดับ/ดาวน์โหลด CSV และสถานะยืนยันข้อมูลปี 2569 จากไฟล์ที่อัปโหลด

## GitHub Pages
อัปโหลด `index.html` และ `data.json` ไปยัง repository แล้วตั้ง Settings → Pages → Deploy from a branch → main → / (root)

## หมายเหตุ
ไฟล์ยืนยันข้อมูลที่ให้มามีข้อมูลการยืนยันล่าสุด แต่ไม่ได้ระบุปีในหัวตารางอย่างชัดเจน จึงนำมาใช้เป็นสถานะ 2569 ตามบริบทชุดข้อมูลล่าสุด และไม่สร้างสถานะยืนยันปี 2568 ขึ้นเอง
